# Changelog

All notable project changes are documented here.

## Unreleased

### Documentation and repository presentation

- Added the Signal Flow visual identity for Media Transcoder.
- Added dedicated project cover and square logo assets.
- Reorganized the main README around actual CLI workflows and safety behavior.
- Added separate Arabic and English guides.
- Added architecture and brand documentation.
- Added structured issue and pull request templates.

No runtime transcoding behavior was changed by this repository presentation update.

## 1.0.0

- Added `probe`, `convert`, and `batch` CLI workflows.
- Added `web`, `small`, `audio-mp3`, `audio-opus`, and `copy` presets.
- Added dry-run support and explicit overwrite protection.
- Added temporary-output handling for safer destination replacement.
- Added supported-media discovery for batch conversion.
- Added automated tests and cross-platform GitHub Actions CI.
